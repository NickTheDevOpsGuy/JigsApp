# Background music

Add your background music file here:

- **Filename:** `background.mp3`
- **Format:** MP3 (works on desktop and mobile)

The game will loop this track when the user turns **Music: on** in the play screen menu (Settings → Audio → Music).

Keep the file size reasonable for web (e.g. 1–3 MB for a 1–2 minute loop). Use royalty-free or properly licensed music.
